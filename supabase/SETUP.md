# Profi.UZ — подключение реальной базы данных

Проект: Самарканд, RU / UZ / TJ.

## Шаг 1. Создать Supabase
1. Создайте проект в https://supabase.com/dashboard .
2. В SQL Editor выполните весь файл `supabase/schema.sql`.
3. В Authentication настройте допустимые способы входа и подтверждение телефона через SMS-провайдера. Для SMS потребуется отдельная настройка и расходы.
4. В Project Settings → API найдите Project URL и **publishable / anon key**. Эти значения допустимы в браузере **только при правильно настроенных RLS**.
5. **Никогда не добавляйте в GitHub service_role key, secret key, пароль базы или токены SMS.**

## Шаг 2. Безопасность и выпуск
- В текущем SQL клиентские профили создаются автоматически. Статус специалиста может назначить только администратор через доверенную серверную операцию; это предотвращает самовольную регистрацию под ролью специалиста.
- Доступ к персональным данным ограничен. Публичный каталог специалистов потребует отдельной таблицы/представления без телефона и личных данных.
- Для рабочего запуска дополнительно нужны подтверждение телефона, правила модерации, лимиты заявок, защита от спама и аудит действий.
- Веб-сайт сейчас работает в демо-режиме через localStorage. Наличие SQL файла **не подключает** сайт к Supabase автоматически.

## Следующий этап
После получения Project URL и publishable/anon key подключить клиент Supabase, авторизацию, серверное хранение заказов и отклики. Секреты передавать не нужно.
